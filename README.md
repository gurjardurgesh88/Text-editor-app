# TextUtils

A simple text utility app built with React. It provides useful tools for working with text.

## Live Demo

https://text-editor-online.vercel.app/

## Features

- Convert text to uppercase
- Convert text to lowercase
- Clear text
- Copy text to clipboard
- Remove extra spaces
- Word and character count
- Dark and light mode

## Tech Stack

- React
- JavaScript
- HTML
- CSS
- Bootstrap

## Getting Started

Clone the repository:

```bash
git clone https://github.com/gurjardurgesh88/Text-editor-app.git
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The app will run locally at:

```text
http://localhost:3000
```
